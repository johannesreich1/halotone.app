アプリ

  • 曲を共有しない限り、私には何も届きません。アプリにはサインインも広告も分析も、データを集めるサードパーティのコードもありません。
  • 曲と設定はデバイスに保存されます。バージョン 1.1 からは、Halotone で iCloud がオンのとき、保存した曲があなたのプライベートな iCloud データベースを通じてデバイス間でも同期されます。読めるのはあなただけで、Apple が自社のプライバシーポリシーに従って扱います。iOS は曲と設定を iCloud やコンピュータへのデバイスのバックアップに含めることもあります。
  • Halotone Plus は Apple の App Store で購入します。支払いは Apple が処理し、私があなたの名前、Apple アカウント、支払い情報を見ることはありません。アプリは App Store に Plus がロック解除されているかどうかを尋ねるだけです。
  • クラッシュレポート。 iOS で「App デベロッパと共有」をオンにしている場合、Apple はあなたを特定しないクラッシュレポートと使用統計を私に送ることがあります。これは「設定」›「プライバシーとセキュリティ」›「解析および改善」でオフにできます。
  • ベータテスト。 TestFlight で Halotone をテストする場合、Apple はあなたが送ったフィードバックを、Apple が TestFlight で示す情報とともに私に共有します。
  • 「動画を共有」は、デバイス上で動画を作成し、どこにも送信しません。「写真」に保存する場合、アプリが iOS に求めるのはライブラリへの追加の許可だけで、ライブラリを見る許可は決して求めません。さらに「見つける」に表示をオンにした場合に限り、曲が共有されます。その仕組みはリンクで共有する場合とまったく同じです。

曲の共有

共有は任意で、このセクションは共有を使う場合にのみ適用されます。共有するすべてのものにコミュニティルールが適用されます。

  • 共有した曲に含まれるもの。 曲を共有すると、Halotone はそれを私のサーバーに送ります。送られるのは、曲そのもの（サウンド、テンポ、キー）、選んだタイトルとアーティスト名、約30秒の音声、ドットの画像、「見つける」に表示するかどうか、共有した日時です。サーバーは再生数と投票数、コピー確認用の曲のフィンガープリントを追加します。リンクを持つ人は誰でも聴くことができ、タイトルとアーティスト名を見ることができます。「見つける」では誰でも同様です。
  • クリエイター ID。 初めて曲を共有、投票、報告するか、アーティストをブロックすると、サーバーはアプリにランダムな ID とシークレットを渡し、iCloud キーチェーンに保管します。サーバーは ID、シークレットのハッシュ、作成日時を保持します。これらはアーティスト名、曲、投票、報告、ブロックとそれぞれの日時に紐付きますが、本名、メールアドレス、Apple アカウントに紐付くことはありません。
  • デバイス確認。 共有するとき、アプリは Apple の App Attest を使って、本物のデバイス上の本物の Halotone アプリであることを証明します。サーバーはこのデバイスの公開鍵とカウンターをクリエイター ID とともに保持し、1回限りのチャレンジを使用されるか期限が切れるまで保持します。このために Apple が私に個人データを共有することはありません。
  • Halotone Plus。 同時に5曲を超えて共有する場合、サーバーは取引番号を使ってアプリの Plus 購入が有効かどうかを Apple に尋ね、その番号と確認日時をクリエイター ID とともに保持します。私があなたの名前、Apple アカウント、支払い情報を見ることはありません。
  • 再生。 共有された曲や「見つける」を開くと、サーバーから読み込まれます。クリエイター ID がある場合、投票とブロックを反映するためにアプリが ID を送ります。再生数は誰が聴いたかを知らずに数えられます。曲のリンクページは、ブラウザの言語を読み取ってその言語で表示し、アプリがその言語に対応していない場合は英語で表示しますが、読み取った言語は保存しません。
  • クリップボード。 初回起動時、アプリはクリップボードを読み取らずに、リンクが含まれていそうかどうかだけを確認します。クリップボードを読み取るのは、あなたがペーストをタップしたときだけで、その後そのリンクの曲を開きます。
  • 保管場所。 Cloudflare（Cloudflare, Inc.、米国）に保管されます。Cloudflare はデータ処理契約に基づいて私の代わりにデータを処理し、曲とそのデータを EU 内に保存します。Cloudflare はページの配信と不正利用の制限のために IP アドレスを処理し、サーバーログを最大7日間保持します。
  • 理由。 あなたが求める共有を提供するため（GDPR 第6条1項b号）、および報告のモデレーションを含め、共有を不正利用から守るという私の正当な利益のためです（GDPR 第6条1項f号）。
  • 保存期間。 共有した曲は、共有をやめるか名前を削除するまで残ります。曲の共有をやめると、音声、画像、曲データ、タイトルはすぐに削除されます。1日の上限とコピー確認が機能し続けるよう、コード、クリエイター ID、日時、フィンガープリントのみが残ります。「見つける」 › 「自分の曲」の名前と曲を削除は、アーティスト名、曲、投票、報告、ブロック、デバイスキー、取引番号をすぐに削除します。データベースの自動復元履歴には、削除されたデータがさらに最大30日間残る場合があり、その後は消去されます。
  • 報告。 曲を報告すると、一人が一度だけ数えられるよう、サーバーは理由をクリエイター ID とともに保持します。私に見えるのは理由と曲で、誰が報告したかは見えません。ルールに違反する曲を削除し、クリエイター ID の共有を停止することがあります。毎日のメールで私に伝えられるのは、届いた報告の数と非表示の曲の数だけです。Resend（Resend, Inc.、米国）がこれを配信し、見えるのはこれらの数字と私のアドレスだけです。曲の削除、クリエイターへの警告、共有の停止が行われた場合、アプリでお知らせするために、サーバーは理由と削除された曲のタイトルを90日間、または共有が停止されている間保存します。クリエイター ID をお持ちの場合、アプリは起動時にこれらのお知らせをサーバーに確認します。
