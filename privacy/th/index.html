นี่คือคำแปลจากฉบับภาษาอังกฤษและภาษาเยอรมัน ซึ่งจะมีผลบังคับใช้หากมีความแตกต่างกัน

Halotone ไม่มีโฆษณา ไม่มีการวิเคราะห์ และไม่มีการติดตาม และเพลงของคุณจะอยู่ในอุปกรณ์ของคุณ เว้นแต่คุณจะแชร์เพลง การแชร์เป็นตัวเลือก หน้านี้อธิบายว่ามีการจัดเก็บอะไรบ้าง

แอป

  • ไม่มีสิ่งใดออกจากอุปกรณ์ของคุณ เว้นแต่คุณจะใช้การแชร์เพลง แอปไม่มีการลงชื่อเข้าใช้ ไม่มีโฆษณา ไม่มีการวิเคราะห์ และไม่มีโค้ดของบุคคลที่สามที่เก็บข้อมูล
  • เพลงและการตั้งค่า จะบันทึกไว้ในอุปกรณ์ของคุณ เว้นแต่คุณจะแชร์เพลง iOS อาจรวมสิ่งเหล่านี้ไว้ในข้อมูลสำรองของอุปกรณ์ไปยัง iCloud หรือคอมพิวเตอร์ ซึ่ง Apple จัดการตามนโยบายความเป็นส่วนตัวของตน
  • Halotone Plus ซื้อผ่าน App Store ของ Apple โดย Apple เป็นผู้ดำเนินการชำระเงิน ฉันไม่เคยเห็นชื่อ บัญชี Apple หรือรายละเอียดการชำระเงินของคุณ แอปเพียงสอบถาม App Store ว่าปลดล็อก Plus แล้วหรือไม่
  • รายงานข้อขัดข้อง หากคุณเลือกใน iOS ให้แชร์การวิเคราะห์กับนักพัฒนาแอป Apple อาจส่งรายงานข้อขัดข้องและสถิติการใช้งานที่ไม่ระบุตัวคุณมาให้ฉัน คุณสามารถปิดได้ที่ การตั้งค่า › ความเป็นส่วนตัวและความปลอดภัย › การวิเคราะห์และการปรับปรุง
  • การทดสอบเบต้า หากคุณทดสอบ Halotone ผ่าน TestFlight Apple จะแชร์ความคิดเห็นที่คุณส่งให้ฉัน พร้อมกับรายละเอียดที่ Apple ระบุไว้ใน TestFlight

การแชร์เพลง

การแชร์เป็นตัวเลือก และส่วนนี้มีผลเฉพาะเมื่อคุณใช้งาน กฎของชุมชนมีผลกับทุกสิ่งที่คุณแชร์

  • สิ่งที่อยู่ในเพลงที่แชร์ เมื่อคุณแชร์เพลง Halotone จะส่งเพลงไปยังเซิร์ฟเวอร์ของฉัน ได้แก่ ตัวเพลง (เสียง จังหวะ และคีย์) ชื่อเพลงและชื่อศิลปินที่คุณเลือก เสียงประมาณ 30 วินาที รูปภาพจุดของเพลง การแสดงใน สำรวจ หรือไม่ และเวลาที่คุณแชร์ เซิร์ฟเวอร์จะเพิ่มจำนวนการเล่นและจำนวนโหวต และลายนิ้วมือของเพลงสำหรับการตรวจสอบการคัดลอก ทุกคนที่มีลิงก์สามารถฟังและเห็นชื่อเพลงและชื่อศิลปินได้ และทุกคนทำได้ใน สำรวจ
  • ID ผู้สร้างของคุณ ครั้งแรกที่คุณแชร์ โหวต หรือรายงานเพลง หรือบล็อกศิลปิน เซิร์ฟเวอร์จะให้ ID และรหัสลับแบบสุ่มแก่แอป ซึ่งเก็บไว้ในพวงกุญแจ iCloud ของคุณ เซิร์ฟเวอร์เก็บ ID ค่าแฮชของรหัสลับ และเวลาที่สร้าง สิ่งเหล่านี้เชื่อมโยงกับชื่อศิลปิน เพลง โหวต รายงาน และการบล็อกของคุณ พร้อมเวลาของแต่ละรายการ แต่ไม่เชื่อมโยงกับชื่อจริง อีเมล หรือบัญชี Apple ของคุณ
  • การตรวจสอบอุปกรณ์ เมื่อคุณแชร์ แอปจะใช้ App Attest ของ Apple เพื่อพิสูจน์ว่าเป็นแอป Halotone จริงบนอุปกรณ์จริง เซิร์ฟเวอร์เก็บกุญแจสาธารณะของอุปกรณ์นี้และตัวนับไว้กับ ID ผู้สร้างของคุณ รวมถึงรหัสท้าทายแบบใช้ครั้งเดียวจนกว่าจะถูกใช้หรือหมดอายุ Apple ไม่แชร์ข้อมูลส่วนบุคคลให้ฉันในเรื่องนี้
  • Halotone Plus หากคุณแชร์เพลงมากกว่าสามเพลงพร้อมกัน เซิร์ฟเวอร์จะถาม Apple ว่าการซื้อ Plus ของแอปถูกต้องหรือไม่ โดยใช้หมายเลขธุรกรรม และเก็บหมายเลขนั้นและเวลาที่ตรวจสอบไว้กับ ID ผู้สร้างของคุณ ฉันไม่เห็นชื่อ บัญชี Apple หรือรายละเอียดการชำระเงินของคุณ
  • การฟัง การเปิดเพลงที่แชร์หรือ สำรวจ จะโหลดจากเซิร์ฟเวอร์ หากคุณมี ID ผู้สร้าง แอปจะส่งไปเพื่อให้โหวตและการบล็อกของคุณมีผล การเล่นจะถูกนับโดยไม่รู้ว่าใครฟัง หน้าลิงก์ของเพลงจะอ่านภาษาของเบราว์เซอร์เพื่อเลือกภาษาอังกฤษหรือเยอรมัน และไม่จัดเก็บไว้
  • คลิปบอร์ด ในการเปิดครั้งแรก แอปจะตรวจสอบเพียงว่าคลิปบอร์ดดูเหมือนมีลิงก์หรือไม่ โดยไม่อ่านเนื้อหา แอปจะอ่านคลิปบอร์ดก็ต่อเมื่อคุณแตะวาง แล้วเปิดเพลงจากลิงก์นั้น
  • สถานที่จัดเก็บ ที่ Cloudflare (Cloudflare, Inc., สหรัฐอเมริกา) ซึ่งประมวลผลข้อมูลแทนฉันตามข้อตกลงการประมวลผลข้อมูล และจัดเก็บเพลงและข้อมูลของเพลงในสหภาพยุโรป Cloudflare ประมวลผลที่อยู่ IP เพื่อส่งหน้าเว็บและจำกัดการละเมิด และเก็บบันทึกเซิร์ฟเวอร์ไว้ไม่เกินเจ็ดวัน
  • เหตุผล เพื่อให้บริการการแชร์ที่คุณขอ (มาตรา 6(1)(b) GDPR) และเพื่อประโยชน์โดยชอบธรรมของฉันในการป้องกันการละเมิด รวมถึงการตรวจสอบรายงาน (มาตรา 6(1)(f) GDPR)
  • ระยะเวลา เพลงที่แชร์จะคงอยู่จนกว่าคุณจะเลิกแชร์หรือลบชื่อของคุณ เมื่อคุณเลิกแชร์เพลง เสียง รูปภาพ ข้อมูลเพลง และชื่อเพลงจะถูกลบทันที เหลือเพียงรหัส ID ผู้สร้างของคุณ เวลา และลายนิ้วมือ เพื่อให้ขีดจำกัดรายวันและการตรวจสอบการคัดลอกยังทำงานต่อไป ลบชื่อและเพลงของฉัน ใน สำรวจ › เพลงของคุณ จะลบชื่อศิลปิน เพลง โหวต รายงาน การบล็อก กุญแจอุปกรณ์ และหมายเลขธุรกรรมของคุณทันที
  • รายงาน หากคุณรายงานเพลง เซิร์ฟเวอร์จะเก็บเหตุผลไว้กับ ID ผู้สร้างของคุณ เพื่อให้แต่ละคนนับเพียงครั้งเดียว ฉันเห็นเหตุผลและเพลง แต่ไม่เห็นว่าใครรายงาน ฉันสามารถลบเพลงที่ละเมิดกฎและหยุด ID ผู้สร้างไม่ให้แชร์ได้ อีเมลรายวันแจ้งฉันเพียงจำนวนรายงานที่เข้ามาและจำนวนเพลงที่ถูกซ่อน Resend (Resend, Inc., สหรัฐอเมริกา) เป็นผู้ส่ง และเห็นเพียงตัวเลขเหล่านี้และที่อยู่ของฉัน

เว็บไซต์นี้

halotone.app โฮสต์โดย GitHub Pages (GitHub, Inc., สหรัฐอเมริกา) และส่งผ่าน Cloudflare (Cloudflare, Inc., สหรัฐอเมริกา) ทั้งสองบันทึกที่อยู่ IP ของผู้เยี่ยมชมทุกคนเพื่อความปลอดภัย ดูคำชี้แจงความเป็นส่วนตัวของ GitHubและนโยบายความเป็นส่วนตัวของ Cloudflare ฐานทางกฎหมายคือประโยชน์โดยชอบธรรมของฉันในการมีเว็บไซต์ที่ปลอดภัย (มาตรา 6(1)(f) GDPR) เว็บไซต์นี้ไม่ตั้งค่าคุกกี้ และไม่ใช้การวิเคราะห์หรือแบบอักษรภายนอก

อีเมล

หากคุณเขียนถึงฉัน ฉันจะใช้ที่อยู่และข้อความของคุณเพื่อตอบคุณเท่านั้น (มาตรา 6(1)(b) และ (f) GDPR) อีเมลถึง support@halotone.app จะไปถึง IONOS SE ในเยอรมนี และถูกส่งต่อไปยังกล่องจดหมาย iCloud Mail ของฉันที่ Apple ฉันจะลบข้อความเมื่อไม่จำเป็นอีกต่อไป

สิทธิของคุณ

ภายใต้ GDPR คุณสามารถขอเข้าถึง แก้ไข ลบ หรือจำกัดการประมวลผลข้อมูลของคุณ คัดค้านการประมวลผล และขอข้อมูลในรูปแบบที่โอนย้ายได้ คุณยังสามารถร้องเรียนต่อหน่วยงานคุ้มครองข้อมูล เช่น หน่วยงานของบาวาเรีย (BayLDA) หากคุณไม่แชร์ โหวต หรือรายงานเพลง หรือบล็อกศิลปิน ฉันจะไม่มีข้อมูลเกี่ยวกับคุณ สำหรับเรื่องอื่น ๆ โปรดเขียนถึงฉัน
