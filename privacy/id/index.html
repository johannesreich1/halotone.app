Aplikasi

  • Tidak ada yang keluar dari perangkat Anda kecuali Anda menggunakan fitur berbagi lagu. Aplikasi ini tidak memiliki proses masuk, iklan, analitik, atau kode pihak ketiga yang mengumpulkan data.
  • Lagu dan pengaturan disimpan di perangkat Anda kecuali Anda membagikan lagu. iOS dapat menyertakannya dalam cadangan perangkat Anda ke iCloud atau komputer, yang ditangani Apple sesuai kebijakan privasinya sendiri.
  • Halotone Plus dibeli melalui App Store Apple. Apple memproses pembayaran; saya tidak pernah melihat nama, Akun Apple, atau detail pembayaran Anda. Aplikasi hanya menanyakan ke App Store apakah Plus sudah dibuka.
  • Laporan kerusakan. Jika di iOS Anda memilih untuk membagikan analitik kepada pengembang aplikasi, Apple dapat mengirimkan kepada saya laporan kerusakan dan statistik penggunaan yang tidak mengidentifikasi Anda. Anda dapat menonaktifkannya di Pengaturan › Privasi & Keamanan › Analitik & Peningkatan.
  • Pengujian beta. Jika Anda menguji Halotone melalui TestFlight, Apple membagikan masukan yang Anda kirim kepada saya, beserta detail yang disebutkan Apple di TestFlight.

Membagikan lagu

Berbagi bersifat opsional, dan bagian ini hanya berlaku jika Anda menggunakannya. Aturan Komunitas berlaku untuk semua yang Anda bagikan.

  • Isi lagu yang dibagikan. Saat Anda membagikan lagu, Halotone mengirimkannya ke server saya: lagu itu sendiri (suara, tempo, dan kuncinya), judul dan nama artis yang Anda pilih, sekitar 30 detik audionya, gambar titik-titiknya, apakah lagu muncul di Jelajahi, dan kapan Anda membagikannya. Server menambahkan jumlah putaran dan suaranya, serta sidik lagu untuk pemeriksaan salinan. Siapa pun yang memiliki tautannya dapat mendengarkannya dan melihat judul serta nama artisnya, dan semua orang dapat melakukannya di Jelajahi.
  • ID kreator Anda. Saat pertama kali Anda membagikan, memberi suara, atau melaporkan lagu, atau memblokir artis, server memberi aplikasi ID dan rahasia acak, yang disimpan di Rantai Kunci iCloud Anda. Server menyimpan ID, hash dari rahasia, dan waktu pembuatannya. Semuanya terkait dengan nama artis, lagu, suara, laporan, dan blokir Anda, beserta waktu masing-masing, tetapi tidak pernah dengan nama asli, email, atau Akun Apple Anda.
  • Pemeriksaan perangkat. Saat Anda berbagi, aplikasi menggunakan App Attest dari Apple untuk membuktikan bahwa ini adalah aplikasi Halotone asli di perangkat asli. Server menyimpan kunci publik perangkat ini dan penghitung bersama ID kreator Anda, serta tantangan sekali pakai sampai digunakan atau kedaluwarsa. Apple tidak membagikan data pribadi kepada saya untuk ini.
  • Halotone Plus. Jika Anda membagikan lebih dari tiga lagu sekaligus, server menanyakan kepada Apple apakah pembelian Plus di aplikasi valid, menggunakan nomor transaksinya, dan menyimpan nomor tersebut serta waktu pemeriksaan bersama ID kreator Anda. Saya tidak melihat nama, Akun Apple, atau detail pembayaran Anda.
  • Mendengarkan. Membuka lagu yang dibagikan atau Jelajahi memuatnya dari server. Jika Anda memiliki ID kreator, aplikasi mengirimkannya agar suara dan blokir Anda berlaku. Putaran dihitung tanpa mengetahui siapa yang mendengarkan. Halaman tautan lagu membaca bahasa browser Anda untuk memilih bahasa Inggris atau Jerman dan tidak menyimpannya.
  • Papan klip. Saat pertama kali dibuka, aplikasi hanya memeriksa apakah papan klip tampak berisi tautan, tanpa membacanya. Aplikasi hanya membaca papan klip jika Anda mengetuk Tempel, lalu membuka lagu dari tautan tersebut.
  • Tempat penyimpanan. Di Cloudflare (Cloudflare, Inc., AS), yang memproses data untuk saya berdasarkan perjanjian pemrosesan datanya dan menyimpan lagu beserta datanya di UE. Cloudflare memproses alamat IP untuk mengirimkan halaman dan membatasi penyalahgunaan, serta menyimpan log server hingga tujuh hari.
  • Alasannya. Untuk menyediakan fitur berbagi yang Anda minta (Pasal 6(1)(b) GDPR), dan kepentingan sah saya untuk melindunginya dari penyalahgunaan, termasuk memoderasi laporan (Pasal 6(1)(f) GDPR).
  • Berapa lama. Lagu yang dibagikan tetap ada sampai Anda berhenti membagikannya atau menghapus nama Anda. Saat Anda berhenti membagikan lagu, audio, gambar, data lagu, dan judulnya langsung dihapus. Hanya kode, ID kreator Anda, waktu, dan sidik lagu yang tersisa, agar batas harian dan pemeriksaan salinan tetap berfungsi. Hapus nama dan lagu saya di Jelajahi › Lagu Anda langsung menghapus nama artis, lagu, suara, laporan, blokir, kunci perangkat, dan nomor transaksi Anda.
  • Laporan. Jika Anda melaporkan lagu, server menyimpan alasannya bersama ID kreator Anda, sehingga setiap orang dihitung satu kali. Saya melihat alasan dan lagunya, bukan siapa yang melaporkannya. Saya dapat menghapus lagu yang melanggar aturan dan menghentikan ID kreator dari berbagi. Email harian hanya memberi tahu saya berapa laporan yang masuk dan berapa lagu yang disembunyikan. Resend (Resend, Inc., AS) mengirimkannya dan hanya melihat angka-angka tersebut serta alamat saya.

Situs web ini

halotone.app di-host oleh GitHub Pages (GitHub, Inc., AS) dan dikirimkan melalui Cloudflare (Cloudflare, Inc., AS). Keduanya mencatat alamat IP setiap pengunjung untuk tujuan keamanan; lihat pernyataan privasi GitHub dan kebijakan privasi Cloudflare. Dasar hukumnya adalah kepentingan sah saya atas situs web yang aman (Pasal 6(1)(f) GDPR). Situs ini tidak menggunakan cookie, analitik, atau font eksternal.

Email

Jika Anda menulis kepada saya, saya menggunakan alamat dan pesan Anda hanya untuk menjawab Anda (Pasal 6(1)(b) dan (f) GDPR). Email ke support@halotone.app tiba di IONOS SE di Jerman dan diteruskan ke kotak surat iCloud Mail saya di Apple. Saya menghapus pesan setelah tidak lagi diperlukan.

Hak Anda

Berdasarkan GDPR, Anda dapat meminta akses, koreksi, penghapusan, atau pembatasan data Anda, menolak pemrosesannya, dan memintanya dalam format portabel. Anda juga dapat mengajukan keluhan kepada otoritas perlindungan data, misalnya otoritas Bavaria (BayLDA). Kecuali Anda membagikan, memberi suara, atau melaporkan lagu, atau memblokir artis, saya tidak menyimpan data tentang Anda; untuk hal lainnya, kirimkan pesan kepada saya.

Perubahan

Jika kebijakan ini berubah, versi baru akan muncul di sini dengan tanggal baru.
